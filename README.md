# PropDesk Web

Frontend web for PropDesk, a property/rental management system.

Built with React, TypeScript and Vite. It connects to the PropDesk backend API through a configurable `VITE_API_URL`.

## Features

- Authentication flow
- Dashboard UI
- Property / rental management views
- API-driven frontend architecture
- Build ready for static hosting

---

This frontend consumes the PropDesk backend API:

- [PropDesk API](https://github.com/tu-user/propdesk-api)

Configure the backend URL with:

```env
VITE_API_URL=http://localhost:8080
```
